# 回転旅団 — Pyxel戦闘プロトタイプ

隊列をローテーションしながら戦う、予測型フォーメーションバトルの最小プロトタイプです。

## ブラウザで遊ぶ

https://kitao.github.io/pyxel/wasm/launcher/?run=jirodasu.rotation-brigade-pyxel.main_jp

スマホはタップ、パソコンはマウス操作のみで遊べます。ゲーム内で矢印キーや決定キーは使いません。

## コア要素

- 3×4フォーメーション
- 固定7人パーティ
- 前列：攻撃・敵の攻撃を受ける
- 中列：攻撃支援・防御支援・遠距離攻撃
- 後列：自己回復・ライン回復
- 戦闘中の判断は「ローテーション」「そのまま」の2択
- 中列の支援は使い切りで、再度中列へ入ると再使用可能
- 敵の行動予定を事前表示
- 乱数なし

## ボス

1. 鉄巨人ゴルム — 誰に攻撃を受けさせ、いつ後ろへ下げるか
2. 翼竜ヴァルガ — 大技時の前列人数をどう調整するか
3. 晶殻獣カルサイト — 弱点露出ターンに高火力陣形を合わせるか

## 表示・演出

- 画面内テキストを日本語化
- 日本語字形はPythonコード内に埋め込み、外部フォントや画像に依存しない
- 攻撃者から対象へ軌跡を表示
- 対象位置にダメージ／回復量を大きく表示
- 行動ごとに「誰から誰へ」「何ダメージ／何回復」を表示
- ターン終了後にキャラ別与ダメージを表示
- 敵の攻撃は前列だけに当たることを常時明示
- 行動中は関係のないキャラを弱く表示し、攻撃者と対象を強調

## 操作

### タイトル
ボスの枠をタップ／クリックすると戦闘画面へ進みます。

### 戦闘開始
「戦闘開始」をタップ／クリックします。

### 戦闘中
- 「一時停止」：自動再生を止める
- 「再開」：自動再生を再開する
- 「次の行動」：1行動だけ進める

### ターン終了時
- 「ローテーション」：中列→前列、後列→中列、前列→後列へ移動
- 「そのまま」：現在の隊列を維持

### 勝敗後
「もう一度」で同じボスへ再挑戦できます。
